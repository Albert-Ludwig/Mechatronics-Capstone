# 独立行人：Nav2 动态避障验证（0.4.0）

日期：2026-10-28。ROS 2 Lyrical / Gazebo Sim 10。

0.3.1 中“行人主动停让”改变了测试条件，不能用它证明 Nav2 能处理独立行人。
0.4.0 删除该逻辑及其配置，保留有限推力、实体几何匹配和行程限制的物理修复。

## 控制职责

行人以标称 0.4 m/s 沿 x=-4.0～2.8、y=0 往返。它的运动节点只读取自身关节反馈
和仿真时间，不订阅机器人位姿、里程计或 TF，也不发布机器人速度。
仅在自身关节反馈过期时保持位置，不因机器人靠近而停让。

机器人控制链为：雷达 `/scan` → Nav2 障碍代价地图 → NavFn 全局规划 /
MPPI 控制器 → velocity_smoother → Nav2 collision_monitor → `/cmd_vel`。
任务节点负责发送目标及失败处理，不执行正常避障控制。实际接触导致的零速度和
取消任务属于失败处理，不能让发生过碰撞的任务通过验收。

## 直接检查由谁停让

仿真约 41.4～43.4 秒，小车保持在 (-1.47665, 0.54657)，
Gazebo 实测 XY 速度为零；行人同时以约 0.3998 m/s 从 x=-1.679 继续走到 x=-0.902。
小车随后恢复运动。这段时间行人没有停让。

Nav2 日志依次记录 SlowCircle 减速、StopCircle 停车、恢复减速和正常运行。
记录见 [逐时位姿和速度](runtime/nav2-v0.4.0-encounter.csv) 与
[Nav2 碰撞监测日志](runtime/nav2-v0.4.0-collision-monitor.log)。
这段记录证明了停车等待由 Nav2 执行；不将它描述为 MPPI 完成了横向绕行。

同一轮任务的返航阶段另附加了只读观测工具，持续至任务完成：

- 收到 `/cmd_vel_nav` 上 1313 条 Nav2 控制器命令，其中 500 条包含明显转向。
- 30 次在 Nav2 全局代价地图的行人双腿区域观测到近致命障碍单元。
  检查区域位于静态地图为空的中间通道，排除了 C 货架附近的静态膨胀影响。
